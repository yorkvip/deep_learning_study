# 丢弃法（Dropout）学习笔记

## 1. 思路：给输入加噪声，但保持期望不变

丢弃法来源于一个朴素的想法：给输入加入噪声后，我们希望噪声**平均下来不影响结果**：

$$\mathbb{E}[X_1] = X$$

对每个元素做如下扰动：

$$
h' =
\begin{cases}
0, & \text{以概率 } p \text{（丢弃）} \\[6pt]
\dfrac{h}{1 - p}, & \text{以概率 } 1 - p \text{（保留并放大）}
\end{cases}
$$

- 以概率 `p` 直接把元素**丢成 0**；
- 以概率 `1-p` 保留，但要**除以 (1-p) 放大**，用来补回丢掉那部分，让期望不变。

通常把丢弃法作用在**隐藏全连接层的输出**上。

## 2. `dropout_layer`：随机丢弃的实现

```python
def dropout_layer(X, drop_out):
    assert 0 <= drop_out <= 1
    if drop_out == 1:
        return torch.zeros_like(X)   # 全丢：直接返回全 0
    if drop_out == 0:
        return X                     # 不丢：原样返回
    mask = (torch.rand(X.shape) > drop_out).float()   # 生成 0/1 掩码
    return mask * X / (1.0 - drop_out)                # 丢掉的置0，保留的放大
```

关键就是 **`mask`**：

- `torch.rand(X.shape)`：生成一个和 X 相同形状的随机矩阵，每个元素是 [0,1) 的均匀随机数；
- `> drop_out`：与丢弃率比大小，**以概率 `1-p` 取 1（保留），以概率 `p` 取 0（丢弃）**；
- `mask * X / (1-p)`：mask=1 的元素保留并放大，mask=0 的置成 0。

三个特判：
- `drop_out == 1`：全部丢弃，返回全 0；
- `drop_out == 0`：全部保留，原样返回；
- `assert 0 <= drop_out <= 1`：丢弃率必须是 [0,1] 之间的概率。

## 3. 怎么理解 `class Net(nn.Module)`

这是一个**带两个隐藏层（每层 256 个单元）、自带丢弃法**的多层感知机。

### 拆成三部分理解

**① `class Net(nn.Module)`：继承基类**
`nn.Module` 是 PyTorch 所有网络的"基类"。继承它，等于声明"我是一个能自动管理参数、自动求导、能被搬到 GPU（`.to('cuda')`）的神经网络对象"。

**② `__init__`：搭积木（买零件）**
定义"这个网络由哪些层组成"，创建对象时自动执行：

```python
def __init__(self, num_inputs, num_outputs, num_hiddens1, num_hiddens2):
    super().__init__()
    self.num_inputs = num_inputs
    # 三个全连接层：784→256（隐藏1）、256→256（隐藏2）、256→10（输出）
    self.lin1 = nn.Linear(num_inputs, num_hiddens1)
    self.lin2 = nn.Linear(num_hiddens1, num_hiddens2)
    self.lin3 = nn.Linear(num_hiddens2, num_outputs)
    self.relu = nn.ReLU()   # 激活函数，放在隐藏层后面
```

**③ `forward`：流水线（数据怎么流动）**
每次调用 `net(X)` 就执行它，定义前向传播的顺序：

```python
def forward(self, X):
    H1 = self.relu(self.lin1(X.reshape((-1, self.num_inputs))))  # 展平→线性→ReLU
    if self.training == True:                                     # 训练中才丢弃
        H1 = dropout_layer(H1, dropout1)                          # 第一隐藏层丢弃 0.2
    H2 = self.relu(self.lin2(H1))                                 # 第二隐藏层
    if self.training == True:
        H2 = dropout_layer(H2, dropout2)                          # 第二隐藏层丢弃 0.5
    out = self.lin3(H2)                                           # 输出 10 个数
    return out
```

数据完整路径：

```
X (批量,1,28,28)
 → reshape (−1,784)         展平成向量
 → lin1 (784→256) → relu   第一隐藏层
 → [训练时] dropout 0.2     随机丢弃第一层输出
 → lin2 (256→256) → relu   第二隐藏层
 → [训练时] dropout 0.5     随机丢弃第二层输出
 → lin3 (256→10)           输出层
 → (批量,10) 的分数
```

## 4. 为什么 dropout 只在训练时执行

用 `self.training` 区分训练 / 推理两种模式：

| | 训练时 (.train()) | 测试时 (.eval()) |
|---|---|---|
| 丢弃 | 随机丢掉 p 的神经元 | **不丢弃**，全部参与 |
| 作用 | 逼网络不依赖单个结点，防过拟合 | 让所有神经元一起决策，输出更稳定 |
| 参数更新 | 参数照常更新 | 参数冻结，不更新 |

这样网络"平时（训练）靠着一部分神经元硬扛也扛得动，所以不会把宝押在个别结点上；考试（测试）时全体上阵"，泛化能力更强。

## 5. 简洁实现

用 PyTorch 现成的 `nn.Dropout`，就不用自己写 `dropout_layer`：

```python
net = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784, 256), nn.ReLU(), nn.Dropout(0.2),
    nn.Linear(256, 256), nn.ReLU(), nn.Dropout(0.5),
    nn.Linear(256, 10),
)
net = net.to(device)
```

`nn.Dropout(0.2)` 自动完成"置 0 + 放大"两件事，且它自己就知道训练/测试何时该生效（`model.train()` / `model.eval()` 会自动切换），不用手动判断。

## 6. 关键结论

- **丢弃法** = 训练时随机丢神经元 + 保留的放大，期望不变。
- **`dropout_layer` 核心** = 用随机掩码 `mask` 决定神经元的"开关"。
- **`Net` 类** = `__init__` 搭网络结构（哪些层），`forward` 定义数据流向（怎么算）。
- dropout 只作用于**隐藏层输出**，且**只在训练时丢弃**。
- 简洁实现用 `nn.Dropout`，自动处理训练/测试切换。
