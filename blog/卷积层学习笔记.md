# 卷积层学习笔记

## 1. 二维互相关运算 `corr2d`

一开始，我们定义了函数 `corr2d(X, K)`，这是计算**二维互相关运算**的函数。

- `Y`：输出矩阵
- `X`：输入矩阵
- `K`：参数矩阵（卷积核/滤波器）

`Y` 是把 `X` 在参数矩阵 `K` 的滑动下，做滑动窗口内的**求和**操作所产生的矩阵。

## 2. 为什么这样操作是合理的

### （1）只需要关注局部区域

对于分辨一个图像，我们不需要模型认识图像的所有部分，只需要能辨认图像中**一定区域内的相邻部分**即可。

参数矩阵 `K` 把 `X` 的相邻部分囊括起来，并以**求和**的形式体现到 `Y` 中。这样模型学到的核就是一个"局部特征检测器"，而不是对整幅图一刀切。

### （2）兼顾了空间结构

互相关运算可以兼顾 `X` 的**空间特性**：

- 某些元素靠得近（相邻）
- 某些元素离得远

这种"远近"关系，通过卷积核在空间上的滑动被保留并体现出来——相邻位置对应同一个核的计算结果，隐私地保留了输入的空间位置信息。

## 3. 用 `nn.Conv2d` 实现卷积层

我们用 `nn.Conv2d`（继承自 `nn.Module`）来实现二维卷积层。

在演示代码里，先给定已知的 `X` 和 `Y`，想让模型**反推**出参数矩阵 `K`。

把需要学习的核打包进 `Conv2d` 层中：

- 输入通道 1
- 输出通道 1
- 权重形状为 `(1, 2)`（即一个 1×2 的卷积核）

```python
conv2d = nn.Conv2d(1, 1, kernel_size=(1, 2), bias=False)
```

## 4. 训练学习卷积核

然后就是 100 轮经典的学习代码：

- 前向传播：`Y_hat = conv2d(X)`
- 计算损失：`loss = (Y_hat - Y)**2` 的均值
- 反向传播 + 更新参数：清零梯度 → `backward()` → 优化器 `step()`

## 5. 效果

学习效果很好，**30 轮内 loss 就降为 0**，模型反推出的卷积核 `K` 非常接近真实值。这说明卷积层的参数是可以通过梯度下降学出来的——这也是卷积神经网络能被"训练"出来的基础。
