# 权重衰退学习笔记

## 1. 什么是过拟合

过拟合可以这样理解：当我们的数据**参数量很小**，却用一个**很大的模型**来拟合时，模型会在训练集上拟合得非常好，就好像能把答案给"背"下来。但在测试集上，效果却很差。

因为模型把数据里的**噪声**也纳入学习了，记住了答案，却没有记住数据本身的趋势。

## 2. 权重衰退：应对过拟合的方法

对于一个过拟合的模型，`w` 通常相对比较大。因为 `x` 只要有一点点变化，`(wx + b)` 整体就要去适应噪声。

那么，只要我们对 `w` 进行一个限制，就可以让拟合曲线更加平滑、稳定。

主要有两种方法：

### 1. 硬约束

给权重加一堵"墙"，告诉 `w`：你就老老实实呆在这个范围里，不许超出。

$$\min_{\mathbf{w}} \; \ell(\mathbf{w}, b) \quad \text{s.t.} \quad \|\mathbf{w}\|^2 \le c$$

意思是：在权重范数不超过 `c` 的前提下，让损失最小化——权重被硬性限制在半径 `c` 的球内。

### 2. 软约束

有点像给权重栓了一根**弹性绳**。你想让 `w` 变大？可以，但你会受到更大的拉力（惩罚）。

这个惩罚直接写进了损失函数里，成为：

$$L = \ell(\mathbf{w}, b) + \frac{\lambda}{2} \|\mathbf{w}\|^2$$

- `ℓ(w,b)`：原有的拟合损失（如均方误差）
- `(λ/2)·‖w‖²`：权重大小的惩罚项
- `λ`（lambda）：**超参数**，控制惩罚力度

`λ` 展示了增大或减小 `w` 在损失函数中所受到的影响——`λ` 越大，权重变化带来的惩罚越大，模型就越"不敢"把权重放大，曲线自然更平滑。

## 3. 训练函数怎么写

1. 初始化 `w`、`b`
2. 定义好 `loss`
3. 对每一个 `(x, y)` 计算 `loss` 并**自动求导**
4. 用 d2l 封装好的优化器 `sgd` 对 `w`、`b` 进行更新

```python
def train(lambd):
    w, b = init_params()
    net, loss = lambda x: d2l.linreg(x, w, b), d2l.squared_loss
    num_epochs, lr = 100, 0.03
    for epoch in range(num_epochs):
        for x, y in train_iter:
            l = loss(net(x), y) + lambd * L2_penalty(w)
            l.sum().backward()
            d2l.sgd([w, b], lr, batch_size)
```

在损失里加上 `lambd * L2_penalty(w)`，就是软约束的实现。

## 4. λ 要怎么调

对训练后的数据进行分析：

- 如果把 `λ` 设为 **0**，相当于**没有正则化**——训练集 loss 很小，但测试集 loss 基本不变，这显然就是**过拟合**。
- 当把 `λ` 调**大**，测试集的 loss 也会随之减小（裂缝被约束住了）。
- 但当 `λ` 超过某个值（比如 10）后，loss 反而**上升**——这时候 `w` 变化对于 loss 的影响太大了，导致 `w` 不怎么变、趋向于 0。模型失去了拟合能力，变成了欠拟合。

所以在实际使用中，`λ` 需要一个合适的中间值：太小挡不住过拟合，太大又把模型"勒"死了。

## 5. 关键代码速查

| 项 | 从0实现 | 简洁实现 |
|---|---|---|
| 惩罚项 | `lambd * L2_penalty(w)` | `SGD` 的 `weight_decay=wd` 参数 |
| 软约束 | 手写 `L2_penalty` | `nn` + 优化器内置 |

简洁实现里，PyTorch 把正则化封装成了 `weight_decay`，等价于在损失里加 `(λ/2)·‖w‖²`。

## 6. 核心结论

- **过拟合** = 模型记住了噪声，训练好、测试差。
- **权重衰退** = 约束 `w` 不让它太大，让曲线平滑、提升泛化。
- **硬约束** = 给 `w` 划硬性范围；**软约束** = 把 `w²` 加权惩罚进损失。
- **λ 是超参数**，靠手动调节/交叉验证来选中间值。
- `w` 是模型参数（梯度更新），`λ` 是超参数（人为调节）。

## 7. 硬约束是怎么变成软约束的

软约束并不是凭空想出来的，它可以从硬约束**推导**出来。

硬约束是一个带条件的最小化问题：

$$\min_{\mathbf{w}} \ell(\mathbf{w}, b) \quad \text{s.t.} \quad \|\mathbf{w}\|^2 \le c$$

直接用拉格朗日乘子法，把约束并进目标函数，引入参数 λ（拉格朗日乘子）：

$$\min_{\mathbf{w}} \ell(\mathbf{w}, b) + \lambda \left( \|\mathbf{w}\|^2 - c \right)$$

因为 `c` 是常数，对求极小值没有影响，可以把它省略，就得到：

$$L = \ell(\mathbf{w}, b) + \lambda \|\mathbf{w}\|^2$$

这就是"硬约束的软化"：不再是"绝不许超过 c"，而是"想超过也行，但要付出代价"。相同的思路也用在 SVM 的软间隔上。

## 8. 为什么用平方（L2）而不是绝对值（L1）

| | L2（平方） | L1（绝对值） |
|---|---|---|
| 形式 | ‖w‖² = Σwᵢ² | Σ‖wᵢ‖ |
| 几何形状 | 圆形约束区 | 菱形（尖角）约束区 |
| 效果 | 把权重**均匀地**压小，一般都很小但不为 0 | 更容易把某些权重**压到恰好 0**，产生稀疏 |
| 偏导 | 在 0 处光滑可导 | 在 ±0 处不可导 |

√ L1 更常用于特征选择（让很多权重变成 0，只剩关键的）；L2 更常用于防止过拟合（所有权重一起变小，保持平滑）。课程里用的是 L2。

## 9. 名字的由来：为什么叫"权重衰减"

看 L2 惩罚项的梯度：

$$\frac{\partial}{\partial \mathbf{w}} \left( \frac{\lambda}{2} \|\mathbf{w}\|^2 \right) = \lambda \mathbf{w}$$

直觉上，每次梯度下降更新时：

$$\mathbf{w} \leftarrow \mathbf{w} - \eta \left( \frac{\partial \ell}{\partial \mathbf{w}} + \lambda \mathbf{w} \right) = \mathbf{w}(1 - \eta\lambda) - \eta \frac{\partial \ell}{\partial \mathbf{w}}$$

即使拟合损失 `ℓ` 没有梯度，每次更新 `w` 也会被乘一个 `(1 - ηλ)`，也就是每轮都会按比例**衰减**一点。这就是"权重衰减"（weight decay）这个名字的由来。

## 10. 调参时的典型现象（参考）

训练约 200 轮后，不同 λ 的表现大致是（d2l 教材典型数据）：

- **λ = 0**（不衰减）：训练 loss 很小（约 0.01），但测试 loss 较大（约 0.10+）→ **过拟合**
- **λ = 10**：测试 loss 明显下降到约 0.07，训练/test 差距变小 → **效果好**
- **λ = 很大**（如 2**）：w 被压得趋近 0，模型退化成近似常数/线性模型，拟合能力不足 → **欠拟合**

这说明正则化是**所有权重一起被均匀压小**，不是只处理个别权重。
